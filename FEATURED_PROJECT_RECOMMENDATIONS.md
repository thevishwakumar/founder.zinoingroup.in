## 5. Implementation Guidelines for Project Cards

### Direct GitHub Repository Linking
- **Recommendation:** Add a dedicated, secondary code action button to technical project cards:
  ```html
  <div class="project__actions">
      <a href="https://github.com/thevishwakumar/documind" class="button button--small button--secondary" target="_blank" rel="noopener noreferrer" aria-label="View DocuMind AI source code on GitHub">
          <i class='bx bxl-github' aria-hidden="true"></i> Code
      </a>
  </div>
  ```
- **Why:** Corporate technology clients and technical evaluators place immense value on inspectable code, automated test suites, and clean commit history.

### Separation of Instagram from Technical Project Cards
- **Strategic Rule:** **Do not place Instagram links inside individual project cards.**
- **Placement:** Instagram belongs exclusively in:
  1. Header / Navigation social strip (if applicable).
  2. Hero section social icons.
  3. Contact section social cards.
  4. Footer global social links.
- **Reason:** Instagram is a brand and lifestyle channel. Mixing Instagram links into technical software cards dilutes professional focus.
